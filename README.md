# AthanorOS Overlay & Portage Binhost

◈ Dual-purpose repository serving as:
1. **Gentoo Portage Overlay** with custom ebuilds and profiles (`profiles/athanor/musl-llvm`).
2. **Binary Package Host (Binhost)**: CI compiles packages, publishes `.gpkg.tar` to GitHub Releases, and serves the `Packages` index and web page via GitHub Pages.

Visit the live site: [https://choccynix.github.io/](https://choccynix.github.io/)
