◈ AthanorOS Portage Binhost & Overlay

Prebuilt packages (musl + llvm + OpenRC) and custom ebuild overlay for AthanorOS.

1. Portage Binhost (Prebuilt Binaries)

Add this snippet to /etc/portage/make.conf:

FEATURES="${FEATURES} getbinpkg"
PORTAGE_BINHOST="https://choccynix.github.io/"
EMERGE_DEFAULT_OPTS="${EMERGE_DEFAULT_OPTS} --getbinpkg=y --binpkg-respect-use=y"

Index metadata: View Packages Index

2. Portage Overlay & Profiles (Source Ebuilds)

Create /etc/portage/repos.conf/athanor.conf:

[athanor]
location = /var/db/repos/athanor
sync-type = git
sync-uri = https://github.com/choccynix/choccynix.github.io.git
auto-sync = yes

Sync and select the musl-llvm profile:

emerge --sync athanor
eselect profile set athanor:athanor/musl-llvm
