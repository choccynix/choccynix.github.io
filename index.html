choccynix Gentoo Repository & Binhost

This is an automated Portage repository and binary package host.

How to Use the Binhost

Add the following lines to your /etc/portage/make.conf:

PORTAGE_BINHOST="https://choccynix.github.io/binhost"
EMERGE_DEFAULT_OPTS="${EMERGE_DEFAULT_OPTS} --getbinpkg"
