🌌 About The Project

Athanor is a high-performance, Gentoo-based Linux distribution built on the principles of divergence, minimalism, and speed. Mainstream computing has accepted bloat, monolithic dependencies, and hand-holding as the default. We reject that.

Athanor is an operating system forged strictly for the enthusiast, the tinkerer, and the power user who demands absolute control over every CPU cycle. If you want an OS that stays out of your way and respects your hardware, you have found it.

⚙️ The Athanor Stack

We strip away the cruft and rebuild the Linux experience from the source up: * Gentoo-Based: Unparalleled flexibility via source-based package management. * musl libc: We drop the immense weight of glibc for a strict, highly efficient libc. * Clang/LLVM: Compiled with modern toolchains for heavily optimized binaries. * OpenRC: A pure, dependency-based init system. Absolutely zero systemd.
