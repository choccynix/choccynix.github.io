choccynix Gentoo Binhost

Automated Gentoo binary package host for AthanorOS.

Configuration

Add this to /etc/portage/binrepos.conf/athanor.conf: 

[athanor]
priority = 9999
sync-uri = https://choccynix.github.io/binhost

Or, for older Portage installations: 

PORTAGE_BINHOST="https://choccynix.github.io/binhost"
