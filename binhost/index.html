Gentoo Binhost Endpoint

This directory serves the Portage binary package index for choccynix.

Configuration

Add the following to your /etc/portage/make.conf:

PORTAGE_BINHOST="https://choccynix.github.io/binhost"
EMERGE_DEFAULT_OPTS="${EMERGE_DEFAULT_OPTS} --getbinpkg"
